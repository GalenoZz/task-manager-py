# 📝 Desktop Task Manager

Aplicação desktop completa para gerenciamento e organização de tarefas diárias, semanais e mensais, desenvolvida em Python com interface moderna e persistência de dados local.

![Python](https://img.shields.io/badge/Python-306998?style=for-the-badge&logo=python&logoColor=white)
![SQLite](https://img.shields.io/badge/SQLite-003B57?style=for-the-badge&logo=sqlite&logoColor=white)
![CustomTkinter](https://img.shields.io/badge/CustomTkinter-2B2B2B?style=for-the-badge)

## 📌 Funcionalidades

- **Categorização Intuitiva:** Separação dinâmica de tarefas por escopo temporário (Dia, Semana, Mês).
- **Interface Gráfica Moderna:** Desenvolvida em CustomTkinter com modo escuro nativo e componentes responsivos.
- **Persistência de Dados (SQL):** Integração com SQLite para armazenamento permanente, mantendo o histórico de tarefas salvo localmente.
- **Gerenciamento em Tempo Real:** Criação e remoção imediata de tarefas na interface com gerenciamento dinâmico de elementos visuais (`destroy()`).

## 🛠️ Tecnologias e Bibliotecas

- **Python:** Linguagem principal do projeto.
- **CustomTkinter:** Framework para a construção da interface gráfica desktop.
- **SQLite3:** Banco de dados relacional embutido para persistência local.
